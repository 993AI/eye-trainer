## 5. 核心算法：Gamma LUT 生成

`GammaController.SetBrightnessAndTemperature(int brightness, int temperature)`
（由 IL 逐条还原）：

```csharp
void SetBrightnessAndTemperature(int brightness, int temperature)
{
    RAMP ramp = new RAMP();
    ramp.Red   = new ushort[256];
    ramp.Green = new ushort[256];
    ramp.Blue  = new ushort[256];

    for (int i = 0; i < 256; i++)
    {
        int v = i * (brightness + 128);              // 基准线性斜坡
        ramp.Red[i]   = (ushort)Math.Min(v * temperature / 6500, 65535);
        ramp.Green[i] = (ushort)Math.Min(v * temperature / 6500, 65535);
        ramp.Blue[i]  = (ushort)Math.Min(v * temperature / 6500, 65535);
    }

    SetDeviceGammaRamp(GetDC(IntPtr.Zero), ref ramp); // gdi32 / user32
}
```

**要点 / 观测**

- 亮度系数 = `brightness + 128`：亮度 0 → 128（约半亮），亮度 100 → 228（约 89% 满量程）。
- 色温系数 = `temperature / 6500`：6500K 为中性；>6500 整体变亮，<6500 整体变暗。
- **重要观测**：R/G/B 三通道使用**完全相同**的表达式 → "色温"滑块在实现上**并未真正改变白平衡/颜色**，只是对三通道做同一个乘性缩放，等价于第二个亮度控制。
- 全程整数运算，`Math.Min` 负责上限裁剪到 65535。
- 每次调用重建 3×256 数组；`SetDeviceGammaRamp` 要求 LUT 长度为 256，否则调用失败。

```csharp
if (brightnessTokenSource != null) {
    brightnessTokenSource.Cancel();
    brightnessTokenSource = null;
    ToggleBrightnessButton.Content = "开始亮度变化";   // 再点一次 = 停止

brightnessTokenSource = new CancellationTokenSource();

int min = (int)MinBrightnessSlider.Value;
int max = (int)MaxBrightnessSlider.Value;
double interval = IntervalSlider.Value;         // 1..15

await Task.Run(() => Loop(), token);
```

#### 渐变式循环（`isGradualMode == true`，step = 1）
```csharp
int step = 1;
int cur = max;
bool increasing = false;
while (!token.IsCancellationRequested) {
    await Dispatcher.BeginInvoke(() => {                       // 更新 UI + Gamma
        SetBrightnessAndTemperature(cur, (int)CurrentTemperatureSlider.Value);
        CurrentBrightnessSlider.Value = cur;
    });
    await Task.Delay(TimeSpan.FromSeconds(interval / 100.0), token);  // 注意 /100
    if (token.IsCancellationRequested) break;

    if (increasing) { cur += step; if (cur >= max) { cur = max; increasing = false; } }
    else            { cur -= step; if (cur <= min) { cur = min; increasing = true;  } }
}
```

#### 直接式循环（`isGradualMode == false`，瞬间跳变）
```csharp
while (!token.IsCancellationRequested) {
    await Dispatcher.BeginInvoke(() => {                       // 跳到最大值
        SetBrightnessAndTemperature(max, (int)CurrentTemperatureSlider.Value);
        CurrentBrightnessSlider.Value = max;
    });
    await Task.Delay(TimeSpan.FromSeconds(interval), token);
    if (token.IsCancellationRequested) break;

    await Dispatcher.BeginInvoke(() => {                       // 跳到最小值
        SetBrightnessAndTemperature(min, (int)CurrentTemperatureSlider.Value);
        CurrentBrightnessSlider.Value = min;
    });
    await Task.Delay(TimeSpan.FromSeconds(interval), token);
    if (token.IsCancellationRequested) break;
}
```

### 6.5 色温变化 `ToggleTemperatureChange_Click`

与亮度变化**结构完全对称**，区别只有：
- `step = 100`（色温量程 1000–10000，跨度 9000）；
- 更新时 `SetBrightnessAndTemperature((int)CurrentBrightnessSlider.Value, curTemp)`，并改 `CurrentTemperatureSlider.Value`；
- 渐变延迟同样是 `interval / 100.0` 秒，直接式是 `interval` 秒。

### 6.6 语义小结

| 模式 | 行为 |
|---|---|
| **直接式** | 每 `interval` 秒在"最大值 ↔ 最小值"之间硬切换（明暗闪烁） |
| **渐变式** | 每 `interval/100` 秒走 1 档，从 max 平滑滑到 min 再滑回；一次完整扫掠约 `(跨度/100)×interval` 秒 ≈ `interval` 秒 |

- **取消机制**：`CancellationTokenSource`；停止时 `Cancel()`，处于 `await Task.Delay(..., token)` 的循环抛 `TaskCanceledException` 被 async void 吞掉，循环退出。
- 亮度与色温各自一个 `CancellationTokenSource`，**可独立启停**。
